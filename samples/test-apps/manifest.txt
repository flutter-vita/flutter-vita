# Real Flutter apps cloned for bug-finding, by URL and pinned commit.

# The checkouts beside this file are gitignored; this list is not. An app that
# exposed a bug has to stay identifiable, or the bug cannot be regression-tested.
#
# Format: owner/repo <commit-sha> [# note]
#
# An app whose changes we carry is our fork of it, and the changes are commits
# on branch vita-<flutter> there. The port itself works that way (ADR-0021)
# and a test app is no different: a patch file cannot be read in the file it
# changes. Apps with no changes are pinned to their own upstream.
#
# Every app is public, so anyone can reproduce a result here from this file.
# Each app is here for a different axis: two apps that fail the same way cost
# two deploys and teach one lesson.
