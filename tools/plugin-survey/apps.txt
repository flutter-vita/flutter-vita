# These are public repositories, listed by URL only -- nothing is vendored and

# (see the glossary): the checkouts are disposable, the list is not, because a

# enough to be findable, which correlates with being polished, which correlates
# with using more plugins. A survey of hobby apps would look different. The
# number this produces is therefore pessimistic for our purposes, and should be
# read as "how bad is it at the high end", not "the average app".
